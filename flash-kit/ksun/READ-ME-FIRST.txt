 S688LN kernel v0.8 — ksun profile (KernelSU-Next + tier-A tuning built IN)
 READ THIS FIRST
========================================================================

WHAT THIS IS
  A custom S688LN GKI kernel built from the exact stock source with:
    * KernelSU-Next v3.3.0 compiled directly into the kernel Image
      (kprobe hook mode). Root lives inside the kernel — nothing is
      written to init_boot or vendor_boot.
    * v0.8 NEW: the tier-A tuning is now a FACTORY DEFAULT in the kernel
      instead of only a runtime module write:
        - default TCP congestion control:  bbr   (stock: cubic)
        - default zram compressor:         zstd  (stock: lzo-rle)
        - KFENCE memory-error sampling:    OFF   (stock: 500 ms)
      These change ONLY default values — no driver/ABI changes — so the
      vendor WiFi/BT modules load exactly like before. Your S26U-Flow /
      KernelBoost module keeps working; it now just confirms the same
      values at boot.

WHY THE WiFi-FIX MODULE IS STILL HERE
  This kernel is self-built, so it trusts only its OWN module-signing
  key and rejects Google's signed rfkill.ko. The included WiFi/BT fix
  module ships THIS build's own signed rfkill.ko (+ usbnet family) and
  loads them at post-fs-data, then the Unisoc WiFi/BT chain. The module
  is root-agnostic: it runs under KernelSU OR Magisk.
  CRITICAL: signing keys are PER-BUILD. Use the boot.img and the
  wifi-fix zip from THIS SAME kit together — a zip from any older
  release is rejected ("rfkill: exports protected symbol") and WiFi/BT
  dies. STEP-2 checks the hashes for you before flashing.

HOW TO ROOT WITH KERNELSU
  1. Install the "KernelSU Next" manager app (v3.3.0 APK, reports
     version 33214 with this kernel).
  2. Open the manager AFTER booting this kernel — it should report
     "Working". That confirms root.
  3. Install the WiFi/BT fix module (the zip in this kit) THROUGH the
     KernelSU manager's Modules tab. Reboot.

GOLDEN RULES (unchanged)
  * NEVER flash blind. First:  fastboot boot boot.img   (temporary).
    Only if root + WiFi + BT + full boot are all good do you flash.
  * Flash the KERNEL/boot only, via FASTBOOTD (`fastboot reboot
    fastboot`). This unit's bootloader-mode fastboot is non-functional.
  * Never touch init_boot / vendor_boot / thermal.

TEST ORDER
  STEP-1-CHECK  -> reads state (no writes)
  fastboot boot boot.img (manual) -> verify KSU manager = Working, WiFi,
    BT, and that lsmod shows the full chain (~248 modules).
  STEP-2-FLASH  -> only after the boot-test passes (fastbootd).
  RESTORE-STOCK-v2 -> panic button back to your stock kernel backup.
